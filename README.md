# Refinement to PDB Deposition and Ensemble Generation Guides
A place where guides for single structure refinement and EMMIVox are written and shared.

Last updated on 11/04/2026\
Current OS: MacOS 27.2 (Golden Gate)

Guides are completed on MacOS, but should be similar on Linux and Windows systems. Submenus may be sorted differently in these operating systems.

Thumbnails are ```gifs``` or videos that can be viewed to see exact actions completed in each step. Feel free to click the image to access the video to orient yourself to the particular program. Ctrl or Cmd + Click will open the video or gif in a new tab.
